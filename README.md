# solution-writer-spar

> 来源分类：**待确认** ｜ 导出批次：review

运营商解决方案编写skill。面向运营商客户经理/解决方案经理，基于需求洞察报告和弹药库（产品资料），使用五步法（需求转译、能力匹配、产品组合、差异化定位、价值量化）生成SPAR格式的解决方案建议书。当用户提到"写方案"、"做解决方案"、"SPAR"、"需求洞察转解决方案"、"面向决策层的方案"时必须使用此skill。

## 安装

把本文件夹整体复制到 WorkBuddy 技能目录：

```bash
cp -r . ~/.workbuddy/skills/solution-writer-spar        # 用户级
# 或
cp -r . <项目>/.workbuddy/skills/solution-writer-spar   # 项目级
```

重启/刷新 WorkBuddy 后即可在对话中触发。
